<Lede>
This article is the living reference for the Ralphy blog kit. It exercises
every <Tag>MDX</Tag> component the library ships, plus every standard
markdown block the engine renders, in roughly the order you'll use them in
real posts. If a new component lands in <Tag kind="accent">index.tsx</Tag>,
add it here first.
</Lede>

## 1 · Type stack

Standard markdown elements render inside `.blog-body`. The hierarchy below
shows every heading level and how it sits next to body type.

### Third-level heading

Body paragraphs sit at 24px / 1.5 by default. They wrap on the article's
prose column (1020px) and inherit `--ink-2` as the foreground. **Bold text
shifts to full `--ink`** and *italic stays the same colour but tilts*. You
can also use `inline code` for short keys, file names, or commands. To kill
a word use ~~strikethrough~~ — handy for "renamed-from" notes.

#### Fourth-level heading

Sub-headings inside long articles. Use sparingly. Display font, uppercase,
slightly tighter tracking.

## 2 · Inline links and tags

Inline links default to **mono chip** styling — every `<a>` reads as a
"follow this" command. See [the generation log spec](https://ralphy.mintlify.app/log-spec)
and [the model routing rules](https://ralphy.mintlify.app/models) for live
examples. External links like [the Remotion docs](https://remotion.dev)
render the same way.

Tags are uppercase chips for product names, model ids, and env vars. Three
kinds: <Tag>neutral</Tag>, <Tag kind="accent">accent</Tag>, and
<Tag kind="warn">warn</Tag>. They sit cleanly inside paragraphs.

## 4 · Callouts — variant D

Big-glyph plates. Four `kind`s: `info`, `good`, `warn`, `danger`.

<Callout kind="info" title="Default callout">
Use `info` for tangents and meta-notes that aren't the article's main thread.
This is the neutral choice when nothing else fits.
</Callout>

<Callout kind="good" title="Reach-for-this callout">
`good` reads as confirmation or a positive heads-up. Often used for cost
savings, free tier reminders, "we already built that".
</Callout>

<Callout kind="warn" title="Edge-case callout">
`warn` is amber. Use for caveats users actually need to read before acting —
"this changes default behaviour", "watch the model swap".
</Callout>

<Callout kind="danger" title="Footgun callout">
`danger` is rose. Reserve for irreversible actions or known-broken paths.
If you find yourself using it more than once per article, the article
probably needs restructuring.
</Callout>

## 5 · CTA banner — variant B

Full-bleed accent plate. One per article, two max. Used to break the prose
column with the action you actually want the reader to take.

<Cta

  caption="Two API keys, zero account. ralphy doctor verifies the install in five seconds."
  href="https://github.com/alecs5am/ralphy"
  cta="Get Ralphy"
/>

## 6 · Lists

Unordered list:

- First item with a longer line that wraps to verify the bullet alignment
  stays clean when text overflows to a second visual line.
- Second item.
- Third item with **bold** and `inline code`.
- Fourth item with a [mono-chip link inline](https://github.com/alecs5am/ralphy).

Ordered list:

1. Brief in, storyboard out.
2. Agent reviews and edits.
3. Render and ship.

Nested list (one level only — beyond that, restructure into Steps):

- Top item
  - Sub item A
  - Sub item B with **bold**
- Another top item
  - Sub item C
  - Sub item D

## 7 · Blockquote

Standard markdown `>` blockquote. Distinct from `<PullQuote>` — quieter,
prose-flow-friendly.

> week and a CMO asks what you spent on hands-and-eyes regens in Q1.

## 10 · Steps — vertical timeline

Numbered timeline for processes or playbooks. The `n` prop is optional —
omit to fall back to CSS counter-style auto-numbering.

<Steps>
  <Step n="01" title="Brief in, storyboard out">
    Drop a one-line brief into <Tag>ralphy new</Tag>. The CLI writes
    `STORYBOARD.md`, `prompts.json`, and a per-scene reference list — all
    checked into git.
  </Step>
  <Step n="02" title="Agent reviews + edits">
    Claude reads `AGENTS.md`, walks the storyboard, swaps weak prompts.
    Human reviews the diff like any pull request.
  </Step>
  <Step n="03" title="Render and ship">
    <Tag>ralphy render</Tag> calls OpenRouter + ElevenLabs, composes through
    Remotion, writes the mp4 plus a generation log entry.
  </Step>
</Steps>

## 17 · Code

Inline `code` reads like `prompts.json` — mono on a `bg-2` plate. Use for
short tokens. Multi-line code goes in a fenced block (no filename tab),
with **server-side syntax highlighting** via `rehype-highlight` /
`highlight.js` — zero JS at runtime, every language detected from the
fence info-string:

```bash
$ brew install alecs5am/tap/ralphy
$ ralphy doctor
✓ openrouter · 200 OK
✓ elevenlabs · 200 OK
$ ralphy new "vertical reel about <your product>"
```

JSON:

```json
{
  "scene": 1,
  "model": "kling-v3.0-pro",
  "persona": "$personas.founder_a",
  "shot": "low-angle POV, hand-held",
  "vo": "Day one, eight thousand orders.",
  "duration_s": 4.5,
  "audio": true
}
```

TypeScript:

```ts
import { Cta } from "@/components/mdx";
import type { ReactNode } from "react";

export function Banner({ children }: { children: ReactNode }): JSX.Element {
  return (
    <Cta
      title="Ship 60 reels"
      cta="Get Ralphy"
      href="https://github.com/alecs5am/ralphy"
    >
      {children}
    </Cta>
  );
}
```

When you want to surface the file name a snippet came from, wrap it in
`<CodeBlock filename …>` — same shell with a tab on top:

<CodeBlock filename="prompts.json" lang="json" meta="42 lines · ralphy ref">
{`{
  "scene": 1,
  "model": "kling-v3.0-pro",
  "persona": "$personas.founder_a",
  "shot": "low-angle POV, hand-held",
  "vo": "Day one, eight thousand orders."
}`}
</CodeBlock>

### Multi-filename code group

For "same task, different file or runtime" snippets, use `<CodeTabs>` —
every tab uses the same filename chrome as a single `<CodeBlock>`, the
active tab connects with the panel below, and the panel cross-fades on
switch via framer-motion.

<CodeTabs>
  <CodeTab filename="install.sh" lang="bash">
```bash
brew install alecs5am/tap/ralphy
ralphy new "vertical reel about my product"
ralphy render reel-001
```
  </CodeTab>
  <CodeTab filename="package.json" lang="npm">
```bash
npm install -g @alecs5am/ralphy
ralphy new "vertical reel about my product"
ralphy render reel-001
```
  </CodeTab>
  <CodeTab filename="bootstrap.sh" lang="curl">
```bash
curl -fsSL https://ralphy.dev/install.sh | sh
ralphy new "vertical reel about my product"
ralphy render reel-001
```
  </CodeTab>
  <CodeTab filename="Dockerfile" lang="docker">
```bash
docker pull ghcr.io/alecs5am/ralphy:latest
docker run -v $(pwd):/work ralphy new "..."
docker run -v $(pwd):/work ralphy render reel-001
```
  </CodeTab>
</CodeTabs>

When tabs aren't real file names (e.g. just a runtime selector), pass
`label=` instead of `filename=` — same chrome, no opinion on what the
text means:

<CodeTabs>
  <CodeTab label="bun" lang="js">
```ts
import { ralphy } from "@alecs5am/ralphy";
await ralphy.render("reel-001");
```
  </CodeTab>
  <CodeTab label="node" lang="js">
```ts
const { ralphy } = require("@alecs5am/ralphy");
await ralphy.render("reel-001");
```
  </CodeTab>
  <CodeTab label="deno" lang="js">
```ts
import { ralphy } from "npm:@alecs5am/ralphy";
await ralphy.render("reel-001");
```
  </CodeTab>
</CodeTabs>

## 19 · FAQ — animated single-open accordion

framer-motion height + opacity transition on toggle, chevron rotates
in lockstep. Single-open group — opening one closes the others.
Respects `prefers-reduced-motion` (falls back to a plain fade). Pass
`open` on any item to expand it by default.

<FAQ>
  <FaqItem q="Why a CLI, not a web UI?" open>
    Because the user we built for is your code-gen agent. Claude / Cursor /
    Codex already write the brief and the deploy script. Asking them to
    drive a CLI is one less integration than wiring them into a SaaS
    dashboard.
  </FaqItem>
  <FaqItem q="Is Ralphy actually free?">
    The binary is MIT and we don't host anything. You pay OpenRouter for
    model calls and ElevenLabs for voice — that's the entire bill.
  </FaqItem>
  <FaqItem q="What happens if OpenRouter is down?">
    Swap providers in `MODELS.md` and restart. We don't lock you to a
    vendor — Ralphy is the orchestrator, not the model host.
  </FaqItem>
</FAQ>
