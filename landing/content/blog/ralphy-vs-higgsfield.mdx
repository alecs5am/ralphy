## The five things you actually own when you self-host

Hosted studios optimize for "type a brief, get a video". Ralphy optimizes for
the next eight months — the part where you're shipping ten reels a week,
regenerating scenes from last quarter, and a CMO asks what you spent on
hands-and-eyes regens in Q1.

- **Your provider keys, your provider rates.** Every model call is direct to
  <Tag>OpenRouter</Tag> and <Tag>ElevenLabs</Tag> at list price. No marked-up
  credits, no platform tier you got grandfathered into.
- **A grep-able generation log.** Each project writes
  <Tag kind="neutral">generations.jsonl</Tag> — input prompt, output URI,
  latency, cost, model id, append-only. Not a 20-row paginated tab.
- **No expiring tokens.** There is no Ralphy account, so no balance to
  expire. You're on OpenRouter's and ElevenLabs' billing cadence — documented
  and rarely-changed.
- **Reference fidelity in your repo.** <Tag kind="accent">ralphy ref</Tag>
  writes structured JSON for master shots, persona descriptors, camera
  grammar — checked into git, re-runnable eight months later.
- **A deterministic render pass.** Final composition is <Tag>Remotion</Tag> —
  React + headless Chromium. Caption timing, transition curves, music
  ducking — all TypeScript you can diff.

## What hosted studios actually have on us

There are three things <Tag>Higgsfield</Tag> and <Tag>Supercomputer</Tag> do
better today. If these matter more than the five things above, hosted is the
right call.

- **Zero setup.** No <Tag>bun</Tag> install, no env vars, no `ralphy doctor`.
  If your team writes zero code, the gap is real.
- **One billing relationship.** OpenRouter + ElevenLabs is two cards, two
  invoices. A studio is one.
- **A web UI designers can click in.** Ralphy is a CLI. The intended user is
  an AI coding agent (<Tag>Claude Code</Tag>, <Tag>Cursor</Tag>) operating on
  your behalf. Without agentic workflows, the seam is sharper.

If you're an AI-native team that already runs `gh`, `claude`, and a dotfiles
repo — the trade-off inverts. Hosted feels like a regression.

## What "AI-native" looks like in practice

The teams that get the most out of Ralphy share a few habits. None unique to
Ralphy — they're how AI-native teams operate in general.

<Steps>
  <Step n="01" title="Treat prompts like code">
    Versioned, reviewed, diff-able. Ralphy puts <Tag>prompts.json</Tag> and
    <Tag>STORYBOARD.md</Tag> in each project — both committed. Your prompt
    history lives next to your application code, not in a SaaS dashboard.
  </Step>
  <Step n="02" title="Let an agent drive the CLI">
    Claude reads `AGENTS.md`, picks the right playbook for the user's intent,
    runs the right `ralphy` verbs, writes the logs. The human reviews the
    diff and the mp4 — same loop as any pull request.
  </Step>
  <Step n="03" title="Retrofit, don't replace">
    Ralphy doesn't replace Figma, Notion, Linear, or your video reviewer. It
    slots between the brief and the render, leaving the rest of your stack
    intact. Migration is opt-in, file-by-file.
  </Step>
</Steps>

If that's the loop you're already in — or planning to be in by Q4 — you don't
need a hosted studio. You need a CLI you can pin to a commit, a Slack channel
where the team can grep prompt history, and an agent that knows when to
refuse to render.

## Frequently asked questions

<FAQ>
  <FaqItem q="What's the difference between Ralphy and Higgsfield?" open>
    Ralphy is an open-source CLI you run on your own machine, calling
    OpenRouter and ElevenLabs directly with your own keys. Higgsfield is a
    hosted studio that owns the pipeline and bills credits. Ralphy gives you
    the audit log, version control, and pass-through pricing; Higgsfield gives
    you a web UI and no terminal.
  </FaqItem>
  <FaqItem q="Does Ralphy replace Higgsfield?">
    For AI-native teams already running CLI tools and AI coding agents — yes.
    For teams that need a designer-clickable web UI with zero setup — no.
    Higgsfield's UI is genuinely good; Ralphy isn't trying to compete on that
    axis.
  </FaqItem>
  <FaqItem q="How much does Higgsfield cost?">
    Reels-Pro is $45-$180/month depending on tier, on top of token costs
    bundled as credits with platform markup. Supercomputer is roughly
    $29-$129/month with a similar credit model. Ralphy is $0 — you pay
    OpenRouter and ElevenLabs directly at their list rates.
  </FaqItem>
  <FaqItem q="Can I use Ralphy and Higgsfield together?">
    Yes. Some teams use Higgsfield's web UI for one-off creative exploration
    and Ralphy's CLI for the production pipeline. The two don't share state,
    but nothing prevents running both in parallel.
  </FaqItem>
  <FaqItem q="Does Ralphy have a free tier?">
    Ralphy itself is free and open source. The cost is whatever you pay
    OpenRouter and ElevenLabs for tokens — typically $0.40-$1.20 per
    6-scene 9:16 reel. There's no platform-side free tier because there's
    no platform to subsidize it.
  </FaqItem>
  <FaqItem q="What models does Ralphy support?">
    Whatever OpenRouter and ElevenLabs expose. Currently the defaults are
    gpt-image-2 (image), kling-v3.0-pro and seedance-2.0 (video), ElevenLabs
    v3 (voice), ElevenLabs Music (music). Adding a new model is a single
    line in MODELS.md — no Ralphy release required.
  </FaqItem>
  <FaqItem q="Can I bring my own brand kit?">
    Yes. Ralphy has first-class `brand`, `persona`, and `ref` resources.
    Drop in logo SVGs, brand voice notes, and master shot images; every
    project pulls them automatically.
  </FaqItem>
  <FaqItem q="What about session memory / consistency across scenes?">
    Reference imagery is the cure for identity drift between scenes. Lock
    your product and model master shots once, then pass them as `--ref` on
    every generate call. Ralphy's prompts.json keeps these references
    explicit and version-controlled, so a scene generated in March can be
    re-rendered identically in November.
  </FaqItem>
  <FaqItem q="Does Ralphy support Russian / non-English voiceover?">
    Yes — through ElevenLabs Multilingual v2. Kling's `--audio` flag is
    canonical for English VO; for non-English we route to ElevenLabs and
    overlay in the editor stage, because Kling's accent slips on non-English
    inputs.
  </FaqItem>
  <FaqItem q="What ships in the box for templates?">
    43 templates across 5 segment-persona categories — B2B SaaS, DTC commerce,
    creator lifestyle, entertainment / viral, cinematic narrative. 5 are
    full-stack production templates; 38 are prompt cookbooks with hooks,
    camera vocab, and worked examples.
  </FaqItem>
  <FaqItem q="Can I run Ralphy without an OpenAI account?">
    Yes. Ralphy never calls OpenAI directly. All LLM / image / video routing
    goes through OpenRouter, which gives you access to OpenAI, Anthropic,
    Google, Black Forest Labs, Kling, Seedance, and others through a single
    API key.
  </FaqItem>
  <FaqItem q="Is Ralphy good for AI-native teams?">
    That's the design target. Ralphy ships with `AGENTS.md` — a routing
    contract the bundled Claude / Cursor agent reads on every turn. The
    agent picks the right playbook for the user's intent, runs the right
    CLI verbs, and writes the logs. Humans review the diff and the mp4.
  </FaqItem>
  <FaqItem q="How do I migrate from Higgsfield to Ralphy?">
    There's no automated import — Higgsfield's storage is opaque. The
    migration looks like: download your reference imagery, transcribe any
    brand voice notes you wrote into the Higgsfield UI, then re-create them
    as `ralphy brand` / `ralphy ref` resources in your repo. After that,
    every new project is on Ralphy. Most teams keep both running for one
    sprint, then deprecate the hosted account.
  </FaqItem>
  <FaqItem q="What's the catch?">
    You have to install a CLI and manage two API keys. If that's a non-starter
    for your team, the rest of the trade-off doesn't matter. Ralphy is built
    for people who already run terminals.
  </FaqItem>
</FAQ>
