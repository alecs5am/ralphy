title: "Old Spice deliberate VFX"
description: "Obviously-fake-on-purpose creatures. The 5 cues that earn the gag instead of reading as AI failure."
---

A 15-second Old Spice-register absurd creature gag — a kelly-green rubber lizard
hands the actor a body wash bottle, a stiff Muppet-eyed sea creature peers from
behind the shower curtain. The cuts are impossible, the prop is deliberately fake,
the actor is unfazed. The whole bit only lands if the creature reads as
"obviously-on-purpose prop", not "AI mistake". That requires all 5 cues — drop one
and it collapses back into AI-slop.

## Brief

> "Make a 15s Old Spice-style ad for a generic men's body wash. Actor in bright
> commercial light delivers the line straight to camera, then a googly-eyed
> kelly-green rubber lizard hands him the bottle. Pastel pink-and-blue tile shower.
> Impossible match-cut into a different bathroom for the punchline."

## Stack

- **Template:** [`cinematic`](https://github.com/alecs5am/ralphy/tree/main/templates/cinematic-narrative/cinematic) (`vibe-style`, cinematic-narrative) — Old Spice register is a custom prompt layer on top
- **Image anchor:** `google/gemini-3-pro-image-preview` (default since 2026-05-20, nano-banana-pro lineage) — three anchors (shower-A, shower-B, lizard prop); multi-ref consistency holds the prop's matte rubber + kelly-green texture across both shower cuts, and the lizard has no labels so gpt-5.4-image-2's typography edge doesn't apply
- **Video:** `kwaivgi/kling-v3.0-pro --audio` — two 8s i2v clips matched at the cut
- **Music:** none — `--audio` baked dialogue + room tone is enough
- **Refs needed:** none (generic body wash, no real Old Spice brand mark)
- **Runtime:** ~9 min cold-start
- **Cost:** ~$3.40 (three images + two 8s Kling pro clips)

## Walkthrough

<Steps>

<Step title="Confirm the brand gate">
"Old Spice register" means the visual grammar (bright pastel commercial light,
mouth-open-mid-shout, full-body 50mm, impossible match-cuts) — not the actual
brand. If the user named "Old Spice the brand", attach a logo ref or refuse.
For style-only, the gate doesn't fire.

```bash
ralphy ref check --text "Old Spice style ad for a generic men's body wash, kelly-green rubber lizard"
# → { "needsReference": false, "reasons": [] }
```
</Step>

<Step title="Scaffold and write the scenario">
```bash
ralphy template use cinematic \
  --project lizard-spice-001 \
  --name "Lizard handoff body wash" \
  --brief "15s Old-Spice-register body wash ad, kelly-green rubber lizard hands actor the bottle, impossible match-cut between two pastel shower sets"
```

Two scenes, 7-8s each, both `body` role with a hook beat baked into scene-01's
first second. VO is two lines, on-camera, in the actor's voice.
</Step>

<Step title="Generate the lizard prop master FIRST">
The lizard is the load-bearing visual gag. Generate the prop in isolation,
verify the 5 cues, then pass it as `--ref` to every scene anchor where it
appears.

```bash
ralphy generate image \
  --project lizard-spice-001 \
  --slot prop-lizard-master \
  --model google/gemini-3-pro-image-preview \
  --size 1024x1024 \
  --prompt "Studio product shot of an obviously-fake rubber lizard puppet held up against a pastel pink wall. Matte rubber not glossy, color is kelly-green (NOT natural reptile green — saturated, deliberately fake), visible mold seams down the belly and along the limbs, stiff arms-out posture like a kids-show prop, oversized googly-eyes (white spheres with loose black pupils that read as Muppet-style craft googly), small puppeteer rod visible at the base. Bright high-key pastel commercial light, naturalistic color, hyperreal NOT cinematic. The viewer must read this as a deliberately fake prop, not as a realistic lizard."
# → workspace/projects/lizard-spice-001/assets/image/prop-lizard-master.png
```

Self-check the 5 cues — matte rubber, kelly-green-not-natural, visible seams,
stiff posture, Muppet googly eyes. All 5 required. If any are missing, regen
once with that cue explicitly emphasized. If still missing, redesign — don't
fight the basin.
</Step>

<Step title="Generate scene-01 anchor (shower-A with lizard handoff)">
Pass the lizard master as `--ref` to lock the prop's identity.

```bash
ralphy generate image \
  --project lizard-spice-001 \

Bright pastel pink-and-mint tile shower set, high-key commercial light, full-body 50mm framing. From frame-left, the kelly-green rubber lizard prop (see ref — matte, seam-visible, googly-eyed, stiff arms-out) extends a generic blue body wash bottle toward him. Hyperreal commercial light, NO moody Tom-Ford chiaroscuro, NO marble bathroom, naturalistic. Old Spice register: bright pastel, mouth open mid-shout, impossible-match-cut energy."
# → workspace/projects/lizard-spice-001/assets/image/scene-01-bg.png
```

<Step title="Generate scene-02 anchor (shower-B punchline)">
Different bathroom for the match-cut. Same actor identity — pass scene-01 as `--ref`

```bash
  --slot scene-02-bg \

Behind him from a different angle the same kelly-green rubber lizard prop (see ref-2) peeks from behind a shower curtain — same matte rubber + seams + googly eyes. Bright pastel high-key commercial light, full-body 50mm, hyperreal commercial register, naturalistic NOT cinematic."

```

<Step title="Generate the two Kling clips">
Each clip is 7-8s, both with `--audio`. The match-cut happens in the editor —
Kling does not handle the cut natively.

```bash

  --project lizard-spice-001 \
  --slot scene-01-vid \
  --model kwaivgi/kling-v3.0-pro \
  --image workspace/projects/lizard-spice-001/assets/image/scene-01-bg.png \
  --duration 8 \
  --audio \
  --prompt "Actor delivers his line to camera, mouth open mid-shout, brief eyebrow lift on punctuation. The kelly-green rubber lizard prop on screen-left holds the bottle out stiffly toward the actor — the prop does NOT move organically, just the puppeteer-rod jiggle. Subtle handheld micro-jitter on the camera. NO music. [VOICE: confident hyped American male, late-30s, English] My new body wash arrives from places men shouldn't have to think about."

ralphy generate video \
  --project lizard-spice-001 \
  --slot scene-02-vid \
  --model kwaivgi/kling-v3.0-pro \
  --image workspace/projects/lizard-spice-001/assets/image/scene-02-bg.png \
  --duration 8 \
  --audio \
  --prompt "Same actor, now mid-shout-into-camera with the bottle raised. Behind him the green rubber lizard pokes out from the shower curtain — stiff lizard movement, googly-eyes wobble, obviously a prop. NO music. [VOICE: same confident hyped American male, escalating] One bottle. One lizard. One bathroom. I make no further claims."
```
</Step>

<Step title="Render with the impossible match-cut">
The editor composition does a hard cut at 8.0s, no transition. Old Spice

## Why this works

The deliberate-VFX gag depends on the audience reading the creature as
"obviously-on-purpose prop" rather than "AI generation failure". The five cues —
matte rubber, kelly-green-not-natural, visible seams, stiff posture, Muppet
googly eyes — together signal "craft prop in a real shower". Drop any one and
the brain reverts to "this is just AI doing a lizard badly". The 5-cue checklist
is non-negotiable; the gag has no fallback.

The Old Spice register is the second load-bearing layer. Bright pastel high-key
commercial light, oiled bare chest, mouth open mid-shout, wide eyes, full-body
50mm, impossible match-cuts. The instinctive default for "premium men's grooming
ad" is Tom-Ford chiaroscuro, marble, tuxedo, ARRI Alexa — that is wrong here.
Tom-Ford reads as moody luxury; Old Spice reads as bright absurdist confidence.
The `NO moody Tom-Ford chiaroscuro, NO marble bathroom` clause is the
strongest known suppressor of the wrong default.

`gemini-3-pro-image-preview` for the lizard prop master and the scene anchors
with the prop + actor refs (multi-ref consistency is gemini's strength, and the
prop has no labels so we don't need gpt-5.4-image-2's typography edge). Kling
carries dialogue via
`--audio` in EN. Two 8s clips with a hard cut at 8.0s in the editor — Kling
cannot do the impossible-match cut inside a single clip, so the cut moves to
composition.

## Variations

- **Different creature.** Inflatable purple shark, plush velvet snail, anything
  that fits the 5-cue rubric. Generate the prop master first, then anchor every
  scene against it.
- **Three-scene escalation.** Add a scene-03 with a third bathroom. Drift starts
  at four scenes — beyond three, the actor's identity needs an additional master
  shot rather than ref-chaining.
- **Russian dub.** Drop `--audio`. Generate silent Kling clips, then ElevenLabs
  `eleven_multilingual_v2` for VO, then composite. Kling `--audio` slips on RU.
- **Real brand.** If the user attaches an Old Spice logo / packaging ref, the
  gate is satisfied — but match-cut into a different brand keeps the gag clean
  while honoring the reference.
- **Single-clip 8s.** Skip the match-cut. One scene, one beat — the gag is the
  prop alone. Cheaper, faster, still works.

## Pitfalls

<Warning>
Drop any one of the 5 cues and the gag collapses. A glossy plastic lizard reads
as bad CGI. A natural-green realistic lizard reads as a wildlife shot. A
non-googly lizard reads as a kids-toy outtake. All 5 cues are required.
</Warning>

<Warning>
Do not let the prompt drift into Tom-Ford / marble / moody-cinema register —
that is the default basin for "premium men's body wash" and it kills the Old
Spice register. The `NO moody Tom-Ford chiaroscuro, NO marble bathroom`
clause is load-bearing.
</Warning>

<Warning>
The match-cut happens in the editor, not in Kling. Kling clips that try to
"hard-cut to a different bathroom" mid-clip drift in identity. Render two
separate 8s clips and cut them in composition.
</Warning>
