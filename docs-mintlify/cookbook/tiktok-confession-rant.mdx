description: "15s selfie POV monolog. Kling --audio for lipsync VO. ElevenLabs Music post-mix."
---

A 15-second 9:16 selfie monolog. One face, eye-level, handheld. The actor delivers a
one-take confession into the lens — three beats: hook, escalation, punchline. Lip-sync
is done by Kling natively via `--audio`; the music bed is added in the editor stage
from a separate ElevenLabs Music pass. The result is a TikTok-native talking-head that
holds the scroll for the full 15s.

## Brief

> "Make a 15s English TikTok rant about how every gym I join makes me feel like
> I'm doing it wrong on day one. Selfie POV, no music in the actor's clip, deadpan
> delivery, snare-led hip-hop instrumental under it."

## Stack

- **Template:** [`talking-head-rant`](https://github.com/alecs5am/ralphy/tree/main/templates/creator-lifestyle/talking-head-rant) (`vibe-reference`, creator-lifestyle)
- **Image anchor:** `google/gemini-3-pro-image-preview` (default since 2026-05-20) — one persona master frame
- **Video:** `kwaivgi/kling-v3.0-pro --audio` — single 15s i2v clip with native lipsync
- **VO:** baked into the Kling clip (English only); Kling reads the dialogue tag in the prompt
- **Music:** `elevenlabs/music_v1` — 16s instrumental, post-mixed under the clip
- **Refs needed:** none (generic archetype, no real person / brand)
- **Runtime:** ~6 min cold-start
- **Cost:** ~$2.40 (one image + one 15s Kling pro clip + one music gen)

## Walkthrough

<Steps>

<Step title="Confirm language and refs">
Kling `--audio` produces clean lipsync only on English and Chinese. On Russian /
Ukrainian / Polish / Spanish it slips accents and ages the voice — drop `--audio`
and route VO through ElevenLabs. Confirm with the user before scaffolding.

```bash
ralphy ref check --text "Make a 15s English TikTok rant about gyms"
# → { "needsReference": false, "reasons": [] }
```

No real person, no brand. Reference-required gate does not fire.
</Step>

<Step title="Scaffold the project from the template">
```bash
ralphy template use talking-head-rant \
  --project gym-rant-001 \
  --name "Gym day-one rant" \
  --brief "15s deadpan English selfie about every gym making me feel wrong on day one"
# → workspace/projects/gym-rant-001/{BRIEF.md, TEMPLATE_ORIGIN.md}
```
</Step>

<Step title="Write the scenario">
The scenarist drafts a single hook scene with `vo_text`, `camera`, and `gesture`.
For a 15s rant, target ~38 words of VO (Kling reads at ~150 wpm with natural pauses).

```bash
ralphy project show gym-rant-001 --scenario
# → scenario.json with one scene-01 (role: hook, target_duration_s: 15)
```

The scenarist quality gate runs `ralphy project score gym-rant-001` before
handing off. If `passed: false`, iterate on hook strength — do not proceed.
</Step>

<Step title="Generate the persona master">
One frame, photoreal, eye-level selfie framing. `gemini-3-pro-image-preview` is
the current default — multi-ref consistency holds the persona for any follow-up
gen and there are no labels in the shot to need gpt-5.4-image-2's typography
edge.

```bash
ralphy generate image \
  --project gym-rant-001 \
  --slot persona-master \
  --model google/gemini-3-pro-image-preview \
  --size 1080x1920 \
  --prompt "Late-20s man, light stubble, grey crew-neck tee, selfie camera at arm's length, eye-level handheld 35mm equivalent, mid-afternoon kitchen window light from screen-left, Kodak Portra 400, hyperreal NOT glossy, naturalistic candid not staged. NO glossy beauty-filter skin, NO enlarged anime-eyes, NO smoothed jawline, NO airbrush, NO Tom-Ford chiaroscuro."
# → workspace/projects/gym-rant-001/assets/image/persona-master.png
```

Run the anatomy check from `art-director/photoreal-humans.md` before moving on.
If the model dropped the selfie framing or the lighting reads "studio",
regenerate once — then redesign the prompt rather than fighting the same basin.
</Step>

<Step title="Generate the video clip with Kling --audio">
Kling reads the dialogue verbatim from a `[VOICE]` tag in the prompt body. Keep
the prompt under 2500 characters (Kling silently 400s above that).

```bash
ralphy generate video \
  --project gym-rant-001 \
  --slot scene-01-vid \
  --model kwaivgi/kling-v3.0-pro \
  --image workspace/projects/gym-rant-001/assets/image/persona-master.png \
  --duration 15 \
  --audio \
  --prompt "Late-20s man holds the selfie camera at arm's length. Deadpan delivery, very slight eyebrow raise on the punchline. Subtle handheld micro-jitter throughout. NO music, NO background score, only voice + room tone. [VOICE: deadpan, mid-energy, English, male, late-20s] Every gym I join makes me feel like I'm holding the dumbbells wrong on day one. The mirror people stare. The trainer corrects my form before I've even started. I just wanted to sweat in peace."
# → workspace/projects/gym-rant-001/assets/video/scene-01-vid.mp4
```

The `NO music, NO background score` clause is load-bearing. Kling silently
bakes ambient music into clips longer than 8s unless the prompt explicitly
forbids it. Music gets added in the editor stage from a separate gen.
</Step>

<Step title="Generate the music bed">
A separate ElevenLabs Music call. Genre + tempo + instrumentation only —
ElevenLabs Music ToS rejects named-artist / named-producer references.

```bash
ralphy generate music \
  --project gym-rant-001 \
  --slot bed-01 \
  --duration 16 \
  --prompt "Lo-fi hip-hop instrumental, 88 BPM, dusty snare on 2 and 4, muted Rhodes chord stabs, vinyl crackle layer, no vocals, no melodic lead, deadpan-comedy register"
# → workspace/projects/gym-rant-001/assets/music/bed-01.mp3
```

If the API returns 422 with a `prompt_suggestion` field, resubmit the
suggested prompt verbatim — it's the ToS-safe rewrite.
</Step>

<Step title="Compose and render">
The editor composition places the Kling clip full-frame, ducks the music bed
to -18 LUFS under the dialogue, and adds karaoke captions from a Scribe pass.

```bash
ralphy generate captions --project gym-rant-001 --audio workspace/projects/gym-rant-001/assets/video/scene-01-vid.mp4
ralphy render gym-rant-001
# → workspace/projects/gym-rant-001/render/final.mp4 (15.0s, 9:16)
```
</Step>

</Steps>

## Why this works

Selfie POV monologs are the highest-share format on TikTok in 2026, and Kling
`--audio` is the only pipeline that produces credible single-take lipsync at the
15s length. Veo 3.1 tops out at 8s and would force a cut; Kling stretches to 15s
with the dialogue baked from the prompt and reads as one continuous take. That
single-take quality is what holds the scroll.

The "no music in the actor's clip" rule comes from a hard Kling behavior: clips
longer than 8s silently bake ambient music unless the prompt explicitly forbids
it. Once a music track is inside the clip, you cannot remove it — the Remotion
composition can only add on top. Banning music in the prompt and adding the bed
later in the editor gives you independent volume control and lets you swap the
track without re-rendering the actor.

The photoreal persona master uses `gemini-3-pro-image-preview` (the registry
default per `MODELS.md` since 2026-05-20) — multi-ref consistency is the
gemini strength and the single-portrait shot has no labels to make
gpt-5.4-image-2's typography edge worth the ~$0.05/image premium plus the
serialized concurrency cap. If you ever scale this recipe to multi-scene
continuity, gemini is already the right call. The anti-AI-slop block
(`NO glossy beauty-filter skin, NO enlarged anime-eyes…`) is the strongest
known suppressor of AI-slop register in the gemini and gpt vocabulary.

## Variations

- **Russian / Ukrainian / Spanish.** Drop `--audio`. Generate a silent Kling clip,
  then ElevenLabs `eleven_multilingual_v2` for VO, then composite. The Kling
  `--audio` path produces accent slip outside English.
- **Hook overlay.** The `talking-head-rant` template supports an optional first-3s
  hook-screenshot (Reddit post / news headline / tweet). Add a `scene-00-overlay`
  slot in the scenario.
- **Length.** Drop to 8s for a faster scroll-stop format — Kling stays clean
  there too. Above 15s, Kling's lipsync drift becomes visible; split into two
  i2v clips with the same persona master as `--first-frame` on the second.
- **Voice register.** Hyped / shouty / British-sarcastic — change the `[VOICE:]`
  tag tone. Validated registers in `MODELS.md` § Voiceover.
- **Music genre.** Lo-fi hip-hop is the default; trap, indie-folk, vaporwave,
  and ambient drone all work as long as the bed stays instrumental and the duck
  level holds.

## Pitfalls

<Warning>
Do not pass `--audio` for non-English VO. Kling reads the text but slips the
accent and ages the voice on every non-English language tested in the model
matrix. Use motion-only Kling + ElevenLabs VO instead.
</Warning>

<Warning>
Do not skip the `NO music, NO background score` clause for clips ≥10s. Kling
silently bakes a music bed into the clip and you cannot extract or replace it
afterwards. The bed must be a separate generation overlaid in the editor.
</Warning>

<Warning>
Kling caps prompts at 2500 characters and 400s above that. Trim setting /
atmosphere copy first when you need to shorten; `[VOICE:]`, `NO music`, and
identity-restating clauses are load-bearing and never trim.
</Warning>
