A 15-second 9:16 single-character Italian brainrot clip — Tralalero Tralala, Tung
Tung Sahur, Ballerina Cappuccina, one of the 33 canonical characters in the
ralphy-assets pool. The character delivers a one-take Italian-gibberish line full
frame. The recipe is short because the only correct path is to pull the canonical
reference from the asset pool — text-only generation drifts the character into
"some shark with shoes" and the meme stops being recognizable.

## Brief

> "Make a 12s brainrot clip with Tralalero Tralala running across a stylized beach
> ranting about losing his Nike sneakers."

## Stack

- **Template:** [`italian-brainrot`](https://github.com/alecs5am/ralphy/tree/main/templates/entertainment-viral/italian-brainrot) (`vibe-style`, entertainment-viral)
- **Character asset:** pulled from `ralphy-assets` pool (`italian-brainrot-characters/tralalero-tralala`)
- **Image anchor:** `google/gemini-3-pro-image-preview` — the character ref locks identity
- **Video:** `kwaivgi/kling-v3.0-pro --audio` — single 12s i2v clip, Italian-gibberish VO native
- **Refs needed:** the canonical pool reference (auto-pulled on `assets pull-pool`)
- **Runtime:** ~4 min cold-start
- **Cost:** ~$1.85 (one image + one 12s Kling clip)

## Walkthrough

<Steps>

<Step title="Check the pool BEFORE writing any prompt">
The canonical character pool ships in the `ralphy-assets` companion repo. Always
list the pool first.

```bash
ralphy assets list --kind italian-brainrot-characters
# → 33 entries: tralalero-tralala, tung-tung-sahur, ballerina-cappuccina,
#   bombardiro-crocodilo, brr-brr-patapim, lirili-larila, ...
```

Tralalero Tralala is in the pool. Skip the prompt-from-text path entirely.
</Step>

<Step title="Pull the canonical character into the project">
```bash
ralphy assets pull-pool italian-brainrot-characters/tralalero-tralala \
  --install brainrot-shark-001
# → workspace/projects/brainrot-shark-001/assets/uploaded/character-ref.png (SHA-256 verified)
```

The pool reference is SHA-256-verified on pull. No auth needed; the cache lives
at `workspace/.ralph/asset-cache/` and is shared across projects.
</Step>

<Step title="Scaffold the project">
```bash
ralphy template use italian-brainrot \
  --project brainrot-shark-001 \
  --name "Tralalero loses his Nikes" \
  --brief "12s full-frame Tralalero Tralala ranting in Italian gibberish about losing his Nike sneakers on a stylized beach"
```
</Step>

<Step title="Generate the scene anchor with the character ref">
The character ref is the load-bearing identity payload. Gemini's multi-ref
strength is exactly what holds Tralalero's exact silhouette across the gen.

```bash
ralphy generate image \
  --project brainrot-shark-001 \
  --slot scene-01-bg \
  --model google/gemini-3-pro-image-preview \
  --ref workspace/projects/brainrot-shark-001/assets/uploaded/character-ref.png \
  --size 1080x1920 \
  --prompt "Tralalero Tralala (see ref — match the exact shark-with-blue-Nike-sneakers silhouette, three legs, grey shark skin, distinctive eye placement) mid-stride running across a stylized AI-meme beach. Saturated turquoise sea, pastel sky, slight surreal lens distortion, AI-meme register, full-frame 9:16. Mouth open mid-shout."
# → workspace/projects/brainrot-shark-001/assets/image/scene-01-bg.png
```

Self-check against the pool ref before moving on. Tralalero specifically has
three legs and blue Nike sneakers — verify both are present. If the model
dropped a leg or changed the shoe color, regen once with that detail
explicitly emphasized. If still wrong, the character is not in the model's
training and the ref alone is not enough — try one tighter crop of the ref or
fall back to manual paste-up in the editor.
</Step>

<Step title="Generate the Kling clip with Italian-gibberish VO">
Kling `--audio` is clean on English and Chinese. Italian gibberish reads as
phonetic-Italian — Kling handles it because the actual sounds are
English-phoneme-adjacent, not because it knows Italian. Keep the line under
35 words for a 12s clip.

```bash
ralphy generate video \
  --project brainrot-shark-001 \
  --slot scene-01-vid \
  --model kwaivgi/kling-v3.0-pro \
  --image workspace/projects/brainrot-shark-001/assets/image/scene-01-bg.png \
  --duration 12 \
  --audio \
  --prompt "Tralalero Tralala running across the beach, three-leg stride, mouth open mid-shout, AI-meme camera handheld micro-jitter, full-frame. NO music, NO background score. [VOICE: hyped Italian-gibberish, deep male, English-phonetic Italian] Trallalero, trallala, porco-dio e porco-allah, ero con il mio fottuto figlio merdardo a giocare a Fortnite, quando a un punto arriva sua nonna Ornella Leccacappella!"
# → workspace/projects/brainrot-shark-001/assets/video/scene-01-vid.mp4
```
</Step>

<Step title="Render">
```bash
ralphy render brainrot-shark-001
# → workspace/projects/brainrot-shark-001/render/final.mp4 (12.0s, 9:16)
```
</Step>

</Steps>

## Why this works

Italian brainrot characters are recognizable IPs in the meme sense — Tralalero
specifically has three legs and blue Nike sneakers, and a Tralalero with two
legs is not Tralalero. The model cannot fabricate the canonical silhouette from
text alone because the character does not exist in any base-model training set
in a strict way — the only clean signal is the pool reference, which captures
the exact silhouette the community recognizes. Text-only generation produces
"a shark with shoes", and the meme stops working.

The asset catalog discipline (AGENTS invariant #12) is non-negotiable here.
Always `ralphy assets list --kind <kind>` before writing a prompt that names a
specific character. If the character exists in the pool, pull it; if it
doesn't, propose adding it to the pool rather than text-generating a drift-prone
reference. The cost of pool-pull is zero (cache hit after first pull); the
cost of text-generating Tralalero is one wasted Kling clip and a video that
doesn't read as Tralalero.

Gemini's multi-ref consistency is the right model choice for character-anchored
work, and it's the current default (2026-05-20) — gpt-5.4-image-2 is only worth
the swap when label typography on a hero product shot must read crisp, which
doesn't apply to brainrot characters. Kling carries the
Italian-gibberish line via `--audio` because gibberish phonetics map onto
Kling's English phoneme inventory; non-phonetic Italian (real Italian sentences
with intonation) would require ElevenLabs.

## Variations

- **Different character.** Tung Tung Sahur, Ballerina Cappuccina, Bombardiro
  Crocodilo, etc. Same recipe — different pool slug on `pull-pool`. The
  prompt's identity-restating line changes to match the character's signature
  features.
- **Multiple characters.** Pull two pool refs and pass both via `--ref`. Gemini
  holds two refs cleanly; three starts to drift one of them.
- **Russian gibberish.** Drop `--audio`. Generate motion-only, then ElevenLabs
  for a deadpan Russian VO with phonetic Italian words. Kling `--audio` slips
  outside English / phonetic-English.
- **8s loop.** Drop the duration to 8s for a tighter scroll-stop and a cheaper
  spend (~$1.20). Italian brainrot is loop-friendly — the meme is the
  character, not the narrative arc.
- **Add to the pool.** If a brief mentions a specific real-world character not
  in the pool, propose adding it to `ralphy-assets` first rather than improvising
  from text. The pool grows by community contribution.

## Pitfalls

<Warning>
Do not text-generate a pool character. "Generate a Tralalero" without `--ref`
produces a generic shark-creature that doesn't read as the meme. The pool
reference is the only durable identity signal.
</Warning>

<Warning>
Do not use `bytedance/seedance-2.0` for i2v on this recipe. Seedance's privacy
filter rejects characters that read as recognizable human-adjacent, and several
brainrot characters trigger it. Stay on Kling.
</Warning>

<Warning>
The Italian gibberish in the `[VOICE:]` tag must be phonetic-English-Italian,
not real Italian sentences. Real Italian intonation drifts Kling's lipsync.
Borrow phrases from existing brainrot canon and adapt the wording.
</Warning>
