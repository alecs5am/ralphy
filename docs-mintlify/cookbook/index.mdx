Battle-tested patterns. Each page is one full video, end-to-end. Brief at the top,
CLI invocations in the middle, render path at the bottom. If a recipe ships in a
template, the template slug is in the `## Stack` block — `ralphy template use <slug>`
to scaffold it directly.

The recipes split into two tracks. The first nine are **production patterns** — actual
video shapes that ship and convert. The last four are **extension patterns** — how
you add a new template, a new skill, a new model, or migrate an existing video into
Ralphy.

## How to read a recipe

Every page follows the same shape:

- **Lede** — what you end up with.
- **Brief** — the example utterance the user would type into chat.
- **Stack** — template slug, models picked, refs needed, runtime, cost ballpark.
- **Walkthrough** — `<Steps>` from brief to render. CLI invocations are complete; copy-paste runs.
- **Why this works** — the design choices, with the source-of-truth doc cited.
- **Variations** — knobs you can tweak (duration, language, aspect, music).
- **Pitfalls** — the failure modes that drift the recipe off-target.
- **Related** — cross-links to concept, working-with, and CLI pages.
