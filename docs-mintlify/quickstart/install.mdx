---
title: "Install"
description: "Drop the ralphy binary on your PATH, add two API keys, verify with ralphy doctor."
---

Three install paths, all produce the same `ralphy` binary at `~/.local/bin/ralphy` (or `/opt/homebrew/bin/ralphy` for brew). Pick the one that fits your machine, then add two API keys and run `ralphy doctor` to confirm everything's wired.

## Install the binary

<Tabs>
  <Tab title="macOS (brew)">
    ```bash
    brew tap alecs5am/tap
    brew install ralphy
    ```

    Verify:

    ```bash
    ralphy --version
    # → 0.1.0
    ```

    Brew handles upgrades — `brew upgrade ralphy` picks up new releases automatically.
  </Tab>
  <Tab title="Linux/macOS (curl)">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/alecs5am/ralphy/main/install.sh | sh
    ```

    The installer detects your OS and arch (darwin-arm64, darwin-x64, linux-x64, linux-arm64, windows-x64), grabs the matching binary from the latest GitHub Release, drops it at `~/.local/bin/ralphy`, and appends a PATH line to your shell rc if needed. On macOS it also strips the `com.apple.quarantine` attribute so Gatekeeper lets the unsigned binary run.

    Reload your shell or open a new terminal, then verify:

    ```bash
    ralphy --version
    # → 0.1.0
    ```

    To install a specific version or a custom directory:

    ```bash
    RALPHY_VERSION=v0.2.0 RALPHY_BIN_DIR=$HOME/bin \
      curl -fsSL https://raw.githubusercontent.com/alecs5am/ralphy/main/install.sh | sh
    ```
  </Tab>
  <Tab title="npm (cross-platform)">
    ```bash
    npm i -g @alecs5am/ralphy
    ```

    The npm package wraps the same binary. Works on Windows without extra setup.

    ```bash
    ralphy --version
    # → 0.1.0
    ```

    Upgrades: `npm update -g @alecs5am/ralphy`.
  </Tab>
</Tabs>

<Note>
Ralphy needs two host-side tools the binary doesn't ship: `bun` (the JS runtime ralphy uses for Remotion rendering) and `ffmpeg` (encode and trim). Install them with `brew install bun ffmpeg` on macOS or your distro's package manager on Linux. `ralphy doctor` will tell you if either is missing.
</Note>

## First doctor pass

Before you add any keys, run `ralphy doctor` to see what's missing:

```bash
ralphy doctor
```

```json
{
  "ralphy": {
    "installed": true,
    "version": "0.2.0",
    "linkedProject": null,
    "cwd": "/Users/you",
    "mode": "binary",
    "home": "/Users/you/.ralphy"
  },
  "deps": { "bun": true, "ffmpeg": true },
  "keys": {
    "OPENROUTER_API_KEY": false,
    "ELEVENLABS_API_KEY": false
  },
  "blockers": [
    "OPENROUTER_API_KEY missing — OpenRouter required (https://openrouter.ai/keys). Run `ralphy setup`.",
    "ELEVENLABS_API_KEY missing — ElevenLabs required (https://elevenlabs.io/app/settings/api-keys). Run `ralphy setup`."
  ],
  "warnings": []
}
```

What each check verifies:

- **`deps.bun`** — `bun` is on your `PATH`. Needed for Remotion bundling and render.
- **`deps.ffmpeg`** — `ffmpeg` is on your `PATH`. Needed for encoding, scaling, audio mix.
- **`keys.OPENROUTER_API_KEY`** — the unified key that unlocks image generation (gemini-3-pro-image-preview, gpt-5.4-image-2), video (kling-v3.0-pro, veo-3.1, seedance-2.0), LLM/vision, and transcription.
- **`keys.ELEVENLABS_API_KEY`** — voiceover (eleven_multilingual_v2, eleven_v3) and music (ElevenLabs Music API).
- **`linkedProject`** — the `ugc-cli` checkout ralphy is pointed at. Set during `ralphy setup`.

For a human-readable view:

```bash
ralphy doctor -p
```

## Add your keys

Get the two keys:

1. **OpenRouter** — sign up at [openrouter.ai/keys](https://openrouter.ai/keys), create a key, top up a few dollars of credit.
2. **ElevenLabs** — sign up at [elevenlabs.io/app/settings/api-keys](https://elevenlabs.io/app/settings/api-keys), create a key. The free tier is enough for one or two test videos.

Then run the setup wizard:

```bash
ralphy setup
```

The wizard asks for the path to your `ugc-cli` checkout (if you don't have one, `git clone https://github.com/alecs5am/ralphy` first), shows a status table of currently-set keys, lets you paste each missing key, and pings the provider's API to verify before saving. Keys land in `<project>/.env`.

<Tip>
Prefer `direnv`? After `ralphy setup` writes `.env`, add an `.envrc` alongside it with `dotenv` so the keys load on `cd`. Ralphy reads from process env; either source works.
</Tip>

For CI or scripts, drive setup non-interactively:

```bash
ralphy setup -y \
  --openrouter-key sk-or-... \
  --elevenlabs-key xi-... \
  --project-dir ~/code/ugc-cli
```

Or pipe a key from stdin: `cat key.txt | ralphy setup -y --openrouter-key -`.

## Verify

Run doctor again:

```bash
ralphy doctor -p
```

You should see both checks green:

```text
 ★ ralphy v0.2.0
   cwd      /Users/you
   project  /Users/you/code/ugc-cli

   Dependencies
   ✓ bun
   ✓ ffmpeg

   API keys
   ✓ OPENROUTER_API_KEY        OpenRouter
   ✓ ELEVENLABS_API_KEY        ElevenLabs

   ✓ ready
```

If anything's red, the `blockers` array tells you the exact next command. Re-run `ralphy setup` to add a missing key, or `brew install bun ffmpeg` to fix the deps.
