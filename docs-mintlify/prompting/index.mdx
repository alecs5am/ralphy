Prompting in Ralphy isn't free-form text. Each modality has a shape that the per-model adapter expects, and each model in `MODELS.md` has a quirk that can burn a $0.42 clip if you ignore it. This section is the deep dive: doctrine first, then per-modality skeletons, then per-model shaping, then the searchable library.

If you only read two pages, read [Philosophy](/prompting/philosophy) (why generic prompts produce AI-looking output) and [Per-model shaping](/prompting/per-model) (which adapter does what to your text on the way out).

## The mental model

A prompt has two layers. The **goal layer** is what you want — "selfie rant for a SaaS hook, 5 seconds, deadpan VO". The **shape layer** is what the model wants — Kling's bracketed dialogue, Veo's 7-part skeleton, Luma's trailing reinforcer.

You write the goal layer. The adapter (`cli/lib/providers/prompt-adapter/`) handles the shape layer. Every `ralphy generate video` call funnels your `NormalizedPrompt` through `adapterFor(modelId)` and emits the model-specific syntax. You never write `[Speaker, deadpan]: "line"` by hand — you describe the dialogue and the Kling adapter brackets it.

The pages in this section teach the goal layer well enough that the shape comes out clean on the other end.

## Hard rules across every modality

Every prompting page repeats these because they don't bend:

1. **All model calls go through `ralphy generate`** — image, video, voiceover, music. Raw `fetch` against OpenRouter or ElevenLabs breaks the gen-log, the cost rollup, and the manifest (`AGENTS.md` invariant #2).
2. **Anti-AI-slop vocabulary is default-on** for any photoreal-human work. Real camera bodies, real film stocks, real defects. The TV-commercial register is the wrong default for UGC.
3. **Ref-required gate fires for named real entities only** — a specific person, a recognizable brand, a known IP. Generic briefs ("a 30-year-old barista") proceed without refs. See [References](/concepts/references).
4. **`MODELS.md` is the source of truth** for model picks. Re-read it before every model call — Claude's training is stale.
