Video prompts have everything image prompts have plus three dimensions: a start state, an end state, and what happens in between. Get the delta between start and end wrong and the model renders a near-still. Get the audio rules wrong and the clip costs $0.70 to redo with VO that doesn't match the lips. This page is the video-specific rules; [Per-model shaping](/prompting/per-model) covers how each adapter rewrites your text.

## The start↔end motion delta rule

Start and end frames must show a **distinct physical beat** — a gesture, a head turn, an expression change. Identical start and end → static video. The model interpolates between the two anchors and if they look the same, the in-between is also the same.

```text
# Bad — start and end are identical
Start: Alex sits at desk, hands on keyboard, neutral expression.
End:   Alex sits at desk, hands on keyboard, neutral expression.
# → Kling renders ~2s of him barely breathing. Wasted clip.

# Good — distinct beat between start and end
Start: Alex sits leaning back, palms flat on the desk, mouth closed, eyes
       on monitor.
End:   Alex sits leaning forward 6 inches, right hand pointing at the screen,
       mouth mid-word, eyes locked on the camera.
# → Kling renders a clean lean-in punctuated by the point gesture.
```

The delta needs at least one of: **gesture change** (palm-open → point-camera), **head turn** (looking at monitor → looking at lens), **expression change** (neutral → eyebrow-raise), **position change** (back-against-cushion → leaning-forward).

This is the highest-impact single rule for i2v with `--first-frame` + `--last-frame`. Skip it and you get a static clip every time.

## Audio: Kling --audio is EN-only

Kling-v3.0-pro's `--audio` flag bakes a voiceover into the clip with native lip-sync. It is **the canonical English VO path** for talking-head UGC — cheaper than ElevenLabs because one call produces both video and audio, and the lip-sync is materially better than post-mix.

It is **unsafe outside English**. Confirmed across noski, venom, and the playbook memory: Kling --audio on Russian produces accent slips, voice-age drift, and occasional cut text. Same failure mode on `bytedance/seedance-2.0` and `google/veo-3.1` for non-English.

| Audience language | Audio path |
|---|---|
| English | Kling `--audio` — single call, native lip-sync |
| Russian, Korean, Spanish, anything else | ElevenLabs `eleven_multilingual_v2` post-mix; Kling motion-only |

**Always confirm the target audience language with the user during intake before defaulting.** The chat language is not the video language — `noski-people-001` wasted 10 min on a default-Russian assumption the user had to override. See [scenarist playbook pre-flight step 1](https://github.com/alecs5am/ralphy/blob/main/docs/playbooks/scenarist.md).

```bash
# English UGC selfie — let Kling do the audio.
ralphy generate video --project en-saas-001 --slot scene-01-vid \
  --prompt "<...includes dialogue line...>" \
  --duration 5 --audio

# Russian UGC selfie — motion only, ElevenLabs in post.
ralphy generate video --project ru-saas-001 --slot scene-01-vid \
  --prompt "<...no dialogue in the prompt body...>" \
  --duration 5
ralphy generate voiceover --project ru-saas-001 --slot scene-01-vo \
  --voice <voice-id> --text "<russian line>"
```

## The no-music ban

Kling auto-bakes ambient music — usually a piano or strings bed — unless the prompt explicitly bans it. The Kling adapter appends `no background music, SFX only` to the Progression block automatically (see `cli/lib/providers/prompt-adapter/kling.ts:53`), but if you're hand-writing prompts or using a different model, you have to ban it explicitly.

```text
Progression: 5s clip, 9:16, no background music, SFX only.
```

Music is **a separate ElevenLabs Music pass** overlaid in the editor stage. Two reasons:

1. **You can't control auto-baked music.** Genre, tempo, mix level — all baked. Useless for UGC.
2. **Mixing requires VO-aware ducking.** The Remotion editor stage knows where the VO sits and can sidechain the music below it.

See [Music prompts](/prompting/music) for the post-mix workflow.

## The voice-tag block for consistency

When a clip carries dialogue, the Kling adapter wraps it as `[Speaker, tone]: "line"`. The speaker tag is derived from the first comma-clause of the subject. To keep voice consistent across scenes with multiple Kling clips, **use the same speaker tag verbatim across every scene** — Kling weights the bracket as a voice identifier.

```text
Scene 1: Dialogue: [Alex, deadpan]: "I'm not going to sugarcoat this."
Scene 2: Dialogue: [Alex, deadpan]: "Here's what actually happened."
Scene 3: Dialogue: [Alex, hyped]:  "And then everything changed."
```

The first-comma-clause of subject (`Alex, 32, dark brown hair...`) becomes `Alex` in the bracket. Keep the first clause stable across scenes; vary the tone if needed.

For non-Kling models, the adapter handles its own dialogue syntax — Veo uses `Dialogue (tone): "line"`, Sora uses `Voice (tone): "line"`. See [Per-model shaping](/prompting/per-model).

## Length caps and resolution

From `MODELS.md` snapshot 2026-05-08, always re-check via `ralphy models list`:

| Model | Durations | Resolutions | Aspects | Notes |
|---|---|---|---|---|
| `kwaivgi/kling-v3.0-pro` | 3–15s | 720p | 9:16, 16:9, 1:1 | 2500-char prompt cap. Silent upgrade to 1080p. |
| `kwaivgi/kling-v3.0-std` | 3–15s | 720p | 9:16, 16:9, 1:1 | Same per-second rate as pro on OpenRouter. |
| `google/veo-3.1` | 4, 6, 8s | 720p, 1080p | 9:16, 16:9 | 8s cap — for 15s you need Kling. |
| `google/veo-3.1-fast` | 4, 6, 8s | 720p, 1080p, 4K | 9:16, 16:9 | Only model in catalog with 4K. |
| `bytedance/seedance-2.0` | 4–15s | 480p–1080p | 7 aspects incl 21:9 | Rejects photoreal-human anchors. |
| `minimax/hailuo-2.3` | 6, 10s | 1080p | **16:9 only** | First-frame only, no last-frame. |

The 2500-char Kling prompt cap is hard — OpenRouter returns 400 after the round-trip if you exceed it. When trimming, cut atmosphere/setting paragraphs first; voice-tag, no-music, on-camera-EN clauses are load-bearing.

## Camera motion vocabulary

Use real camera-operator language. The training corpora are full of cinematography forum posts and IMDb trivia; the vocabulary is well-attested.

| Term | What it does |
|---|---|
| `dolly-in` / `dolly-out` | Camera moves toward / away from subject on a track. Smooth. |
| `push-in` / `pull-back` | Same as dolly but verb-form. |
| `whip-pan` | Fast horizontal rotation, motion-blurred. Use as transition motivation. |
| `rack-focus` | Focus shifts between near and far subject. Narrative beat. |
| `handheld` | Slight unstable jitter. Default for UGC selfie. |
| `locked tripod` | Zero camera movement. Default for product hero. |
| `gimbal` | Smooth floating motion. Avoid for "real person" UGC — reads professional. |
| `crane up` / `crane down` | Vertical movement, reveals scale. |
| `tracking shot` | Camera moves with subject, matched speed. |

Avoid `panning camera`, `moving camera`, `dynamic shot` — the model has no specific corpus for these.

## i2v anchor picks

When you have a strong first-frame image, i2v gives you tighter control than t2v. Pick the model by what's anchoring:

- **Photoreal human anchor:** `kwaivgi/kling-v3.0-pro` only. `bytedance/seedance-2.0`'s privacy filter rejects photoreal-human anchors with `InputImageSensitiveContentDetected.PrivacyInformation`, even when the human is itself AI-generated. Validated across tokyo, noski, venom postmortems.
- **Cartoon / brainrot / non-human anchor:** Either works. Seedance is stronger at sharp physics motion.
- **Landscape / hands / abstract motion:** Either works. Seedance for fast motion, Kling for slow narrative.
- **Last-frame + first-frame (multi-frame):** Kling v3.0-pro fixed the `400 not in a valid base64 format` issue on 2026-05-19 via auto-C2PA-strip in `resolveImageRef()`. If you still hit the 400, fall back to seedance for the multi-frame path on non-human content.

```bash
ralphy generate video --project <id> --slot scene-01-vid \
  --prompt "<motion description>" \
  --duration 5 \
  --image workspace/projects/<id>/assets/image/scene-01-bg.png \
  --model kwaivgi/kling-v3.0-pro
```

## Aspect ratio for video

Same rules as image, applied to motion:

- **9:16** — selfie POV, TikTok native, single character, default for UGC.
- **1:1** — broadcast-realism (caught-on-TV trends). Per the broadcast-square rule, never 9:16 for these.
- **16:9** — YouTube, cinematic reference. Avoid in feed compositions unless letterboxed into a 9:16 canvas (the meme-header format).
- **21:9** — cinema. Only `bytedance/seedance-2.0` supports it.

`alibaba/wan-2.7` is the only model with 3:4 / 4:3 portrait magazine aspects in the catalog. Use for editorial-magazine spreads.

## Failure modes and the one-retry rule

Per the [regeneration playbook](https://github.com/alecs5am/ralphy/blob/main/docs/playbooks/art-director/regeneration.md): **one retry max** on the same approach. If the second attempt also misses, redesign the scene with different staging.

Concrete example from glitter-cream-001:

```text
Take 1: "jar near cheek, finger taps the lid"
        → Kling renders as "applying powder compact". Miss.
Take 2: "jar near cheek, NOT applying makeup, finger taps lid clearly visible"
        → still "powder compact". Miss.

Don't take 3.

Redesign: "jar tilted at arms-length, two-handed, dropper held above"
        → completely different staging, different basin. Worked first try.
```

Negation (`NOT X`) rarely escapes a strong source-archetype basin. When a verbal description triggers a known basin (`hand near face holding something` → `applying makeup`), the model has 10,000× more training data for the canonical interpretation than for your variant. Redesign with different framing / posture / camera angle to pivot into a different basin.

## CLI surface

```bash
# Standard video gen — default model is kwaivgi/kling-v3.0-pro.
ralphy generate video --project <id> --slot scene-01-vid \
  --prompt "<motion>" \
  --duration 5 \
  [--image <ref-url-or-path>] \
  [--model <id>] \
  [--audio]               # English VO only
  [--last-frame <path>]   # i2v multi-frame

# Dry-run for cost preview without spending credits.
ralphy generate video --project <id> --slot scene-01-vid \
  --prompt "<...>" --duration 5 --dry-run
# → resolved request body + cost estimate, no submit

# Regen — append-only, lands at scene-01-vid.v2.mp4.
ralphy generate video --project <id> --slot scene-01-vid --prompt "<revised>" --duration 5

# Inspect the live model catalog.
ralphy models list                 # all video models, live from OpenRouter
ralphy models show kwaivgi/kling-v3.0-pro   # durations, resolutions, aspects
```
