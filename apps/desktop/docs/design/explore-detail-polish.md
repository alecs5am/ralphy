# Explore detail polish

## Audit and direction

Preserve the existing category routes, square gallery cards, neutral light/dark
tokens, blue controls, typography, real waveform data and agent handoff. The
current split spreads short descriptions across a fluid column, leaves capped
previews floating in space, and hides the actual prompt next to duplicated
technical text. Sounds allocates too much width to titles and inserts a new row
when playback starts. Visuals currently demonstrates static SVGs only.

Design read: a compact creative workbench for media makers, with a visible
working result across the available window width. Taste dials: variance 5, motion 6 inside
previews, density 8. Existing product controls are the design system; landing
page typography and spacing rules do not apply.

## Changes

- Full-width detail layouts: Visuals places its composition above a multi-column
  Customize panel; prompts and templates balance the complete frame with their
  working instructions. Effects keep a compact companion rail. Primary actions
  stay in the header, and provenance and source code stay in a closed disclosure.
- Templates expose their inputs and an inspectable shot sequence. Prompts expose
  editable variables and the actual resulting prompt without duplicate code.
- Visuals include original animated photo and type compositions, with live
  controls, pause, reduced motion and reusable source in the agent attachment.
- Effects and Visuals use the same filled ruler control as Create.
- Sounds uses bounded columns and stable row heights, including active playback.
- Catalog-backed related collections continue below each detail, with matching
  templates, motion, effects and sound suggestions. Prompts have three authored
  directions each; templates expose the selected step's inputs and output.

References: the supplied Artlist and Create screenshots; Reelfolio's live
composition previews at https://reelfolio.io; Inspo MCP component-playground
research. Reuse interaction ideas, not third-party code or artwork.

## Verification

Inspect each category and detail at wide and narrow available widths, verify
prompt edits and selected settings reach Copy/Use in chat, check playback does
not move neighboring rows, and run the desktop validation entry points.
