# Infographic animation mode

> **Status:** done — 2026-06-16
> **Filed:** 2026-06-15
> **Folder:** issues

## Context

Ralphy has motion-design and typography-animation mode docs, plus HyperFrames data-in-motion skill material. It still needs a concrete `infographic-animation` route for data, metrics, comparisons, and explainer visuals.

## What

Add an infographic animation mode that turns structured data or a brief into animated charts, callouts, comparisons, and narrated explainer Units.

## Why it matters

Operational, SaaS, and educational content often needs clear animated information rather than UGC or cinematic footage. This mode broadens Ralphy beyond ad-like media.

## Scope / acceptance

- Add mode doc and route fixtures.
- Define accepted inputs: CSV/table, bullets, metrics, product comparison, or URL-derived stats.
- Require source citation or user-provided data for factual claims.
- Specify HyperFrames chart/overlay components and fallback visuals.
- Add eval criteria for readability, truthfulness, pacing, and text density.
- Link to distribution pack and accessibility checks.
