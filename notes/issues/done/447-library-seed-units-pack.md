## Context

The library needs strong examples for content modes, benchmarks, and user trust. Several internal projects already contain useful deliverables and postmortem-proven workflows.

## What

Package a curated set of internal projects into public or local seed Units with clean provenance, thumbnails, previews, and mode metadata.

## Why it matters

The mode system needs real examples. Seed Units also give agents benchmark material and users a visible sense of what Ralphy can produce.

## Scope / acceptance

- Pick 10-15 internal deliverables across video, image-pack, carousel, poster, and motion-design formats.
- Form Units with clean `unit.json` metadata and provenance where possible.
- Add thumbnails/previews and distribution copy.
- Validate each Unit through the relevant readiness scorecard or current eval equivalent.
- Publish or stage them using the existing templater/library flow.
- Document which modes still lack seed examples.
