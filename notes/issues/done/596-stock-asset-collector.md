# `ralphy stock`: find and pull free licensed overlay assets

> **Status:** done — 2026-10-30 (`ralphy stock search|pull|credits` over five free sources, each its own file-scoped connector; pull records a `stock.pull` Run at $0 and an Artifact revision with license provenance, and writes an append-only copy under `artifacts/<images|videos|sfx|music>/`; verified with live keyless searches on Simple Icons, Commons and Internet Archive)
> **Filed:** 2026-10-30
> **Folder:** issues
> **Severity:** medium
> **Category:** assets / editor / CLI / connectors

## Context

Finance and investing shorts overlay many collected assets: brand logos, photos of people and places, b-roll video, SFX (whoosh, cash register, ding) and a music bed. Ralphy can generate media and pull references (`ref pull`), but it has no way to find free stock assets with a known license, and nothing records where an overlay came from or what credit it needs. Agents search the web by hand, download files into the tree, and lose the license and author on the way.

## What

- `ralphy stock search <query> --kind image|video|audio|logo [--source <id>...] [--limit n] [--orientation vertical|horizontal|any] [--license commercial|any]`: JSON candidates (stable id, source, kind, title, page URL, media URL, preview URL, size or duration when known, license short name and URL, author, a ready attribution string, `commercialOk`, `attributionRequired`). The default `--license commercial` keeps only items that allow commercial use and modification (no NC, no ND). Nothing is downloaded.
- `ralphy stock pull <candidate-id...> --project <id> [--slot <name>]`: re-resolves each id at its source, downloads it, registers it as an Artifact revision (Run + Attempt, cost 0, provenance: source, page URL, license, author, attribution) and places a copy in the Project tree under `artifacts/<images|videos|sfx|music>/` for `index.html`. Append-only: an existing file is never overwritten (a `.v2` name is written instead), nothing is deleted.
- `ralphy stock credits --project <id>`: the markdown attribution block for every stock item pulled into the Project, for the post caption or description.
- Sources (v1, all free, official APIs only, one descriptive User-Agent): Openverse (images, audio; keyless), Wikimedia Commons (images, video, audio, SVG drawings; keyless), Internet Archive (video, PD and CC without NC/ND only; keyless), Simple Icons (brand logos from a pinned jsDelivr package version; CC0 icon data, trademark caveat), Pexels (photos, video; free `PEXELS_API_KEY`, skipped with a note when missing).
- Each source is its own connector file under `cli/lib/providers/` (AGENTS.md invariant #1): own host constants, injectable fetch, file-scoped in `tests/unit/agents-md-invariants.test.ts`; `PEXELS_API_KEY` only through `cli/lib/providers/credentials.ts`.

## Scope / acceptance

- Unit tests per connector: response parsing, license filter, id round-trip; zero network (fixtures through injected fetch).
- Integration test on a temp store root: `stock pull` writes the Artifact revision with provenance and the file in the Project tree, a second pull does not overwrite, `stock credits` lists the item.
- Editor skill tells agents to collect overlay assets with `stock search/pull` and to put `stock credits` in the post copy.
- `docs/cli-surface.generated.md` regenerated; lints and unit tests green.

## Resolution

- Verb: `cli/commands/stock.ts`, registered in `cli/index.ts`. `stock search` resolves no scope (like `catalog`), unless `--workspace` / `--project` is given, so a Workspace-stored Pexels key is visible; `stock pull` and `stock credits` resolve scope like any project verb and need a store root (`E_MIGRATION_INCOMPLETE` otherwise).
- Connectors (one host family per file, injectable fetch, `StockSourceError` on HTTP failure, none in the generation registry): `cli/lib/providers/openverse.ts`, `wikimedia-commons.ts`, `internet-archive.ts`, `simple-icons.ts` (pinned `simple-icons@16.30.0`), `pexels.ts` (`PEXELS_API_KEY` through the new `pexels` descriptor in `credentials.ts`). Shared, host-free code in `cli/lib/stock/`: types and the one User-Agent (`Ralphy/<version> (+https://github.com/alecs5am/ralphy)`), license normalization, HTTP (timeout, byte cap, 429 with Retry-After), media sniffing, search fan-out, pull, credits.
- Ids: `openverse:image|audio:<uuid>`, `commons:File:<name>`, `archive:<identifier>`, `simple-icons:<slug>`, `pexels:photo|video:<n>`. `pull` re-resolves each id at its source, so the recorded license is the current one.
- License filter: `--license commercial` (default) keeps items allowing commercial use AND modification; unknown licenses fail it. `--license open` also drops ShareAlike (CC BY-SA, GFDL), since a BY-SA overlay puts share-alike terms on the published video; Openverse is asked for `license=by,cc0,pdm` then. `pull` applies the same filter and refuses what fails it unless `--license any`.
- Slow sources: each source has its own search deadline (default 10 s, `--timeout <sec>`). At it every request of that source is aborted (no socket or timer outlives the search) and the source is reported as `error` with "no answer within ..." while the others answer.
- Commons relevance: CirrusSearch also matches description and category text loosely ("supercomputer data center" returned aurora photos). Results are re-ranked by where the query terms occur (3 per term in the file title or object name, 1 per term only in the description or categories) and a page is dropped unless its title holds a term or its other text holds them all. Live, the same query then returned data center and supercomputer files only. Internet Archive only ever returns public domain and commercial + modification CC items (the server query excludes NC / ND with slash-free wildcards; the backend rejects `/` inside one).
- Pull: Run `stock.pull`, Attempt provider = source id, cost 0, revision metadata `{ operation: "stock", source, candidateId, title, pageUrl, mediaUrl, license, licenseUrl, author, authorUrl, attribution, commercialOk, modificationOk, attributionRequired, shareAlike, notes, projectPath, sha256 }`, usage role `overlay`. Bytes are sniffed; a body that is not the asked-for media fails the Run and writes nothing. Tree copy: images and logos `artifacts/images/`, video `artifacts/videos/`, audio `artifacts/music/` when the source calls it music or it runs over 30 s, else `artifacts/sfx/`. Default slot `logo-<slug>` (Simple Icons) or `stock-<title>-<6 hex of the id>`. Identical bytes reuse the file; new bytes get `<slot>.v<N><ext>`; nothing is overwritten or deleted.
- Source choices: Commons TIFF / oversized originals download the 1920 px render, video the best MP4 / VP9 transcode at most 1080 lines (Theora-only files are skipped); Archive the largest MP4 at most 1080 lines under 500 MB; Pexels the original photo and the MP4 at most 1080 lines; Simple Icons SVGs get the brand hex as `fill`.
- Credits: `stock credits` reads the provenance from the store, one line per candidate id, required credits first; `--markdown` prints only the block.
- Live check (2026-10-30, keyless): `stock search nvidia --kind logo` (Simple Icons 1 + Commons 11 kept), `stock search "stock exchange" --kind video --source commons archive` (Commons 12, Archive 4), `stock search whoosh --kind audio` (Commons 10). Openverse answered HTTP 504 after 60 s for every uncached query that day, with or without license filters (a server-side outage; a cached query returned the shape the parser expects); with the deadline the search reports it after 10 s and the other sources still answer. Not verified live: Pexels (no key on the machine; fixture-tested only) and a healthy Openverse.
- Unrelated: `tests/unit/fal-elements.test.ts` is flaky (it failed once, then passed twice; it asserts the order of parallel element uploads in the mocked fal connector) and touches no file changed here.
- Tests: `tests/unit/stock-sources.test.ts` (fixtures in `tests/fixtures/stock/`), `tests/integration/stock-pull-596.test.ts` (in-process on a temp store root with the fetch injected, plus the real CLI entry for scope and validation), `tests/unit/agents-md-invariants.test.ts` (each source host file-scoped, `PEXELS_API_KEY` descriptor-owned).
