# Agent substrate media OS

> **Status:** idea
> **Filed:** 2026-06-15
> **Folder:** ideas

## Context

Strategic brainstorming on 2026-06-15. The user approved track 1: make Ralphy the best execution substrate for agents that produce media. The product promise is not "humans use a CLI"; it is "turn Claude Code/Codex-style agents into a reliable content factory."

## What

Ralphy should become the media operating system under agent chat: stable project state, content modes, research, refs, model routing, generation, queueing, eval, repair, provenance, Unit formation, and distribution packaging. The CLI remains utilitarian and agent-facing; it gives agents deterministic verbs, logs, gates, and resumable state.

## Why it matters

Agents are currently the real UI. If the substrate is strong, many chat surfaces can use it: Codex, Claude Code, Desktop, CI, or future cloud workers. If the substrate is weak, every surface inherits the same agent-dependent output quality.
