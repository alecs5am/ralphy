# Crowdsourced metric collection from app users

> **Status:** idea
> **Filed:** 2026-10-28
> **Folder:** ideas

## Context

Many outlier tools collect metrics through a browser extension: numbers are read from the videos a user already watches. Discussed with the owner on 2026-10-28 as a free way to scale the trend corpus.

## What

An opt-in desktop or extension feature that records public metrics of videos the user views, contributed to a shared corpus.

## Why it matters

Scales with users at zero request cost. Risks: it reads from logged-in sessions, which platform terms may forbid (Instagram especially), and it carries account risk for the user. Needs explicit consent, clear disclosure and an owner decision before any work.
