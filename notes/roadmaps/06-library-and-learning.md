# Library, memory, and knowledge flywheel roadmap

> **Status:** roadmap source
> **Filed:** 2026-06-16
> **Folder:** roadmaps
> **Related issues:** #113, #117, #417, #419, #420, #425, #447, #448, #459

## Purpose

Make Ralphy compound. Successful projects should become reusable production
inputs. Failures should become scoped lessons. The library should be an
execution asset for agents, not only a public gallery.

## Target capabilities

- Route map for every kind of learning.
- Unit to template, style, recipe, asset, and benchmark extraction.
- Memory entries with negative scope.
- Guideline and model warning proposals from postmortems.
- Library QA that verifies media, metadata, provenance, and usage instructions.
- Community upload validation path later.

## Knowledge surfaces

Use the right surface for each lesson:

- Memory: durable user or workspace preference, failure rule, or model heuristic.
- Guideline: reusable prompt craft and quality criteria.
- Mode rule: content-mode-specific routing or required input.
- Template: repeatable content structure.
- Style: reusable visual language.
- Recipe: reusable technical effect or editing pattern.
- Asset: reusable prop, person, voice, location, track, or reference pack.
- Benchmark: example used to evaluate future outputs.
- MODELS.md: model capability, failure, or routing knowledge.
- Issue: missing CLI feature, bug, or system gap.

## Workstreams

### Unit extraction

Issue families:

- Unit provenance completeness.
- Template extraction from successful projects.
- Style extraction from visual outputs.
- Recipe extraction from HyperFrames/effects.
- Asset role extraction.
- Benchmark candidate extraction.
- Maintainer review UI or report.

### Failure distillation

Issue families:

- Postmortem to memory proposal.
- Postmortem to guideline proposal.
- Postmortem to model warning.
- Postmortem to issue.
- Negative-scope enforcement.
- Duplicate lesson detection.

### Library quality

Issue families:

- Broken media checks.
- Metadata schema validation.
- Preview generation.
- Usage instruction linting.
- Provenance presence.
- License/source status.
- Agent execution smoke tests.

### Public and workspace library

Issue families:

- Workspace-local template lifecycle.
- Public library publishing gate.
- Library search and matching.
- Library versioning.
- Community submission quarantine.
- Review and promotion workflow.

## Acceptance ladder

1. Route map exists and is used by postmortems.
2. Successful Units can propose reusable entities.
3. Reusable entities pass library QA.
4. Benchmarks are seeded from real Units.
5. Failure lessons update the correct knowledge surface after review.
6. Agents can retrieve library entries as production inputs.
