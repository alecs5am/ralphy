# Distribution and publishing roadmap

> **Status:** roadmap source
> **Filed:** 2026-06-16
> **Folder:** roadmaps
> **Related issues:** #403, #423, #443, #458

## Purpose

Make "ready to post" a first-class deliverable. Users need platform-ready media,
copy, thumbnails, filenames, specs, safe-area validation, and package exports,
not only raw mp4 or png files.

## Target capabilities

- Channel-aware distribution packs.
- Platform spec validation.
- Social copy and hashtag generation.
- Thumbnail and first-frame selection.
- Export bundles for manual publishing.
- Later seam for scheduling, direct uploads, and performance import.

## Acceptance ladder

1. Finished Unit can produce a basic distribution pack.
2. Platform specs validate selected outputs.
3. Social copy is included without duplicating copy logic.
4. Export bundle is usable for manual publishing.
5. Batch packs can be generated in bulk.
6. Performance import seam is documented for later.
