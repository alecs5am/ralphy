## What I did NOT find in verified sources

A few of the topics I couldn't fully close — better to say so than fabricate links:

1. **gpt-image-2 community prompt guides** — official OpenAI documentation exists (links above), but community-curated prompt libraries at the "awesome-gpt-image-prompts" tier I couldn't find at a high enough quality bar. A search for `awesome gpt-image prompts` mostly returns Midjourney/DALL-E-era results.
2. **Virality-scoring skills specifically as SKILL.md** — there are plenty of articles with metrics (section 5), but a concrete `virality-scorer/SKILL.md` by a respected author I didn't run into. The template will need to be written from scratch on top of the benchmarks from section 5.
3. **Production-grade reverse engineering of videos specifically for marketing** — there are general-purpose video-watching plugins (section 6), but a skill that specifically does "shot list → palette → pacing → generation recipe" for reproducing through Seedance/Kling doesn't exist yet. That's an open slot you can take.
4. **Codex / Cursor specific video skills** — Skill format is an open standard and many awesome-lists (section 7) support cross-platform, but Codex-native video skills as a distinct category don't exist.
